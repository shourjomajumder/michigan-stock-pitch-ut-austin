# Code

The scripts used for the calculations in the pitch, grouped in the same topic folders as `data/`. Input paths point at the matching files in `data/`, resolved from the repo root. Saved `.out` files and screenshots show the output as used on the slides. A few scripts need the output of an earlier script in the same folder, a private consensus file (Bloomberg, not included) or an API key, and will stop with a missing-file message until those are supplied. Python packages: `requirements.txt`.
